## Milestone 2: Individual Datasets and Audit Plans

### Erin Chon — German Folklore and National Identity

My project examines how the Brothers Grimm's collection
and classification of folktales contributed to perceptions
of German national identity.

The initial custom dataset contains 50 Grimm fairy tales that
includes ATU classifications and researched historical
source information.

The project also includes Python scripts for dataset
creation and validation, documentation, an audit plan,
and a reflection.

[View Erin's Milestone 2 Project](erin-grimm-folklore/README.md)

### Rui Yang — Greek Myths as Teaching Tools

My project examines how ancient authors used myths of divine
punishment, and whether a story teaches the same lesson each
time it is retold.

The initial custom dataset contains 72 versions of 50 myths, where
each row is one myth as told in one ancient source, plus 111 function
claims recorded separately with their evidence.

The project also includes a Python script for validating the data
and auditing it against Theoi.com, documentation, an audit plan,
and a reflection.

[View Rui's Milestone 2 Project](rui-greek-mythology/README.md)
